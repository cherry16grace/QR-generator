QR Code Generator

A fast, clean, and user-friendly web application that generates QR codes instantly from text, URLs, phone numbers, and more. This lightweight project is built using pure HTML, CSS, and JavaScript with a responsive and modern user interface.

✨ Features
🚀 Instant QR Code Generation
Generate QR codes in real time with a single click.
🔗 Supports Multiple Input Types
Create QR codes for:
URLs
Plain text
Phone numbers
Emails
Custom data
📥 Download QR Code
Save generated QR codes as image files.
📱 Responsive Design
Mobile-friendly interface that works smoothly on all screen sizes.
🎨 Clean User Interface
Modern UI with smooth interactions and simple navigation.
⚡ Lightweight Application
Built using only HTML, CSS, and JavaScript without heavy frameworks.
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and responsive design
JavaScript (ES6) – Dynamic functionality and QR generation
QR Code API / JavaScript Library – QR code creation functionality
